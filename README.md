# Pizza-CRM
### Pizza-CRM - пет-проект для освоения новых знаний, в котором будут реализованы:
* Монолитная архитектура
* Микросервисная архитектура
* Отказоустойчивость
* Покрытие тестами
* Устойчивость к высокой нагрзке

### Как использовать - How to use:
Наличие python какой-то версии
Наличие docker 

Скачивание репозитория
`git clone https://github.com/K4DJee/pizza-CRM.git`

Запуск конфигурации файла docker-compose.uml

Запуск приложения
uv run fastapi dev
